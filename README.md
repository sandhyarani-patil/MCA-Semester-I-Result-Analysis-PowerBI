# MCA Semester-I Result Analysis — Power BI

## Project Overview
This Power BI project provides a comprehensive analysis of MCA Semester-I student academic performance. The dashboard transforms raw result data into actionable visual insights, helping track pass/fail trends, subject performance, and overall student achievements.

## Key Insights & Visualizations
- **Overall Pass vs Fail Percentage**: Pie chart showing overall result distribution.
- **Subject-Wise Analysis**: Bar charts comparing pass and fail rates across all subjects.
- **Performance Metrics**: Detailed breakdown of student marks and performance indicators.



## Tools & Technologies
- **Power BI Desktop**: Data modeling, DAX queries, and dashboard visualization.
- **Excel / CSV**: Data source and initial cleaning.
